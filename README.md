## Set Up Instructions
We ran this project on Visual Studio Code

Before running the project, make sure you perform the following installs: 
* npm install lucide-react
* npm install react-router-dom
* npm install –save react-zoom-pan-pinch

To run, ensure the directory is in ‘my-app' and run ‘npm run dev’ in the terminal. This should provide you a browser link.

After clicking the link, open in open dev mode (f12) and set the screen dimension to iPhone 14 pro max to simulate the project as a mobile app (we used Edge to perform the demo).

### _Note_
_You may find that there's quite a bit of missing functionality. As this was a graded piece of work with time constraints, we only focused on developing functionality for the key functions we highlighted in our assignment, so don't expect a seamless application that can actually save lives in the event of natural disaster._
